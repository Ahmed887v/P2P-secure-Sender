Privacy Policy

Secure Share sends one user-selected file using end-to-end encryption. The developer does not operate a storage server for your files.

Data we do not collect

  • No account, email, or contacts
  • No advertising identifiers
  • No analytics SDKs
  • No full-disk file inventory

Permissions

  • Internet: to publish the receiver link and transfer the chosen file
  • Notifications: to show transfer progress
  • Files: only the single file you pick in the system picker
  • Photos and videos: optional, never required for sending a regular file

Processing

The selected file is read in chunks from disk, encrypted on your device, and written by the receiver to disk or browser private storage. A local signaling service and SSH tunnels (optional user-owned ngrok) carry encrypted chunks only. We cannot read the file. Resume continues from the last verified chunk if a tunnel drops.
