# نقل آمن — نسخة سطح المكتب

حزمة مستقلة لجهاز الكمبيوتر. انقل ملفا واحدا مشفرا لأي شخص يفتح رابطا في المتصفح.
نفس بروتوكول تطبيق أندرويد: HTTP+WS محلي على المنفذ 8080، أنفاق SSH متعددة المسارات، استئناف ونك.

## المحتويات

| الملف | الوظيفة |
|-------|---------|
| `app.py` | واجهة المرسل والمراقب |
| `bootstrap.py` | تثبيت المتطلبات بعد موافقتك |
| `core/` | الخادم والتشفير والإرسال والأنفاق |
| `assets/icon.png` | أيقونة التطبيق |
| `requirements.txt` | مكتبات Python |

## 1. فك الضغط

فك هذا الأرشيف في مجلد واحد، ثم ادخل إليه من التيرمينال.

## 2. المتطلبات على جهازك

- Python 3.10 أو أحدث
- اتصال إنترنت لفتح Serveo / Pinggy / localhost.run
- رمز ngrok اختياري من https://dashboard.ngrok.com/get-started/your-authtoken

## 3. التشغيل

```bash
cd p2p-desktop
python3 app.py
```

عند أول تشغيل يظهر سؤال تثبيت المتطلبات. اضغط موافق.

## 4. الإعدادات

من زر الإعدادات:

- اللغة: عربي أو English
- اللون: داكن / أزرق / أخضر
- رمز ngrok: اختياري كنفق إضافي

بعد الحفظ يعاد فتح التطبيق.

## 5. ترتيب الاستخدام

1. اترك التطبيق مفتوحا. الخادم وأنفاق SSH تشتغل تلقائيا.
2. انسخ رابط المستلم من المربع العلوي، أو شاركه. لا يظهر 127.0.0.1.
3. المستلم يفتح الرابط في المتصفح ويبقى على الصفحة.
4. المستلم ينسخ معرف الجهاز ويبعثه لك.
5. الصق المعرف في مربع المعرف.
6. اضغط اختر الملف وحدد ملفا واحدا.
7. المستلم يضغط قبول.
8. عند اكتمال النقل تظهر رسالة: انتهينا بنجاح.
9. اضغط بدء من جديد أو إغلاق.

المرسل يتصل بـ `ws://127.0.0.1:8080/ws` محليا. المستقبل يصل عبر النفق العام.

## 6. ملاحظات

- يرسل ملفا واحدا في كل مرة، وليس مجلدا.
- حجم القطعة 49152 بايت مثل أندرويد. القراءة من القرص بالفهرس وليس تحميل الملف في الذاكرة.
- الاستئناف و`chunk_nack` و`have_bits` يعملان عند انقطاع النفق.
- القبول في صفحة المستلم مرة واحدة للملف كله.
- اترك التطبيق مفتوحا حتى يصل الشريط إلى 100٪.

## 7. أيقونة سطح المكتب اختياريا

يمكنك إنشاء اختصار يشير إلى:

```bash
python3 /المسار/p2p-desktop/app.py
```

واختر `assets/icon.png` كأيقونة.
