# نقل آمن — نسخة أندرويد (Google Play)

حزمة مستقلة لتطبيق أندرويد. المستقبل لا يثبت شيئا: يفتح رابطا في المتصفح فقط.

البناء يتم من التيرمينال عبر Gradle، بدون Android Studio.

## لماذا هذه النسخة مناسبة لمتجر بلاي

- لا تطلب صلاحية كل الملفات `MANAGE_EXTERNAL_STORAGE`
- اختيار الملف عبر Storage Access Framework (ملف واحد يختاره المستخدم)
- الوصول للصور اختياري ومحدود حسب موافقة المستخدم
- لا تنزّل ملفات تنفيذية من الإنترنت بعد التثبيت
- خادم الإشارات مدمج داخل التطبيق (ليس Python على الهاتف)
- خدمة أمامية ظاهرة أثناء النقل فقط
- targetSdk 35 وminSdk 26
- سياسة خصوصية داخل التطبيق وفي `PLAY_STORE.md`
- لا إعلانات ولا تتبع ولا جمع حسابات

عند أول فتح تظهر شاشة إعداد: اضغط موافق وبدء. التطبيق يشغّل الخادم ونفق إنترنت مدمج (بدون تشغيل ثنائي ngrok على الهاتف حتى لا يُغلق التطبيق). يظهر رابط `https://…` يعمل لأي جهاز ومن أي مكان. أبقِ التطبيق مفتوحا والإشعار ظاهر حتى يفتح المستلم الرابط. رمز ngrok اختياري. الإرسال يقرأ الملف بالقطعة من القرص. المستلم يكتب على القرص أو OPFS. القبول مرة واحدة. الاستئناف يكمل بعد سقوط النفق.

## 1. فك الضغط

فك الأرشيف على جهاز لينكس أو ويندوز فيه اتصال إنترنت.

## 2. بناء التطبيق من التيرمينال

```bash
cd p2p-android
chmod +x build-android.sh
./build-android.sh
```

السكربت يثبت JDK 17 وAndroid SDK إن لزم، ثم ينتج:

- `dist/p2p-secure-share.apk` للتثبيت المباشر للاختبار
- `dist/p2p-secure-share.aab` لرفع Google Play

للتوقيع قبل الرفع إلى بلاي:

```bash
export KEYSTORE_FILE=/path/to/release.jks
export KEYSTORE_PASSWORD=your_password
export KEY_ALIAS=upload
export KEY_PASSWORD=your_password
./build-android.sh
```

بدون هذه المتغيرات يُوقَّع البناء بتوقيع تصحيح فقط، وهذا لا يُرفع لمتجر بلاي.

## 3. بعد تثبيت التطبيق على الهاتف

1. افتح التطبيق.
2. في شاشة أول تشغيل اضغط موافق وبدء (رمز ngrok اختياري).
3. انتظر حتى يظهر رابط نفق حقيقي مثل `https://xxxx.serveousercontent.com/receiver.html` أو `https://xxxx.free.pinggy.net/receiver.html`. لا تشارك `dashboard.pinggy.io` ولا `console.serveo.net`.
4. حدّث التطبيق دون إلغاء التثبيت:

```bash
adb install -r dist/p2p-secure-share.apk
```

لسحب لوجات التطبيق من الهاتف:

```bash
adb logcat -c
adb logcat -s P2PShare:I AndroidRuntime:E *:S
```
5. من الإعدادات يمكن تغيير اللغة واللون (داكن/أزرق/أخضر).
6. أبقِ التطبيق مفتوحا حتى يفتح المستلم الرابط ويكتمل النقل.
7. المستلم يفتح الرابط وينسخ المعرف.
8. الصق المعرف، اضغط اختر الملف، ثم أرسل.
9. المستلم يضغط قبول مرة واحدة للملف كله.
10. عند اكتمال النقل تظهر رسالة: انتهينا بنجاح. إن انقطع النفق يكمل من آخر قطعة سليمة.

لا تغلق التطبيق حتى نهاية النقل.

## 4. ملاحظات بلاي

اتبع `PLAY_STORE.md` حرفيا قبل الرفع: وصف المتجر، سياسة الخصوصية، Data safety، وفيديو يوضح اختيار الملف المحدود.
